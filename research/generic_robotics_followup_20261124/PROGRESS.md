## 已确认的改动

异步感知原先把旧图像中的物体位置与最新 TCP 配对，产生错误的相对漂移。现在使用图像采集时对应的 TCP 和夹爪状态，重复使用同一帧不能凑成验证窗口；持有距离、漂移和时间窗口阈值保持原值。新增三项反例测试覆盖时间错配、重复帧和真实相对运动。

经验提取会在最后一次失败后重新建立变量，防止较早尝试的对象绑定污染候选。候选保留失败原因与证据引用。冻结评测会保留预算耗尽和任务失败，不因这些结果剔除条件；只有协议错误、源码变化或未确认关闭才中断。

HTTP 429 已增加 Retry-After 与有界等待；最多两次等待重试，每次请求独立计入决策预算，等待计入墙钟，可停止/换目标。持续限流后进入保护保持；异常结束后从 Runtime 同步最终预算。四项限流测试及完整 Python 380 / Node 130 检查已通过。
