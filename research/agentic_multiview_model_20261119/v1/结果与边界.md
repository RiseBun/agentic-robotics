# 真实模型多视角对照：闭环完成，但不等于通用能力

作业 20759。模型 gpt-5.6-sol、OpenAI Responses、reasoning off；相同源码、提示词、受限技能、验证阈值与累计预算。两个冻结种子 67/68，stack/restack，每条件一次，共 8 次，逐对交替顺序。模型从初始场景解释目标并生成短程序，没有固定程序准备或人为遮挡，经验检索关闭。

冻结包 SHA256 `71e893617ac2b5090fc65f579149cb1fa677d4168c77f1933d95d30c8f6b5a8e`；Python 服务摘要 `e5d651bf68e9c2585f7e9a734d2bb250b9f0bc00c6ba0a9c046240bed5aec5ce`。基线只用中央相机，候选增加同一步的腕部 RGB-D 与受限点云融合。所有任务关闭后才导出独立评测记录；模型主机正常退出，随后取消实验服务并关闭自建转发。

## 机制证据

- 候选的 28 次执行模型请求实际携带中央和腕部图像，来源、控制步和采集时间可关联。
- 模型决策时的当前观测没有出现可用的融合支撑证据；这不代表融合没起作用。生成程序执行期间会重新读取当前状态，Runtime 在实际释放前也重新检查。
- stack/67 候选后一次释放、restack/67 与 restack/68 候选释放，共 3 次检查由 `public_rgbd_union` 可用证据放行，水平跨度比分别约 0.873、0.925、0.824。不是缓存旧帧、私有位置或放宽原 0.4 阈值。
- stack/68 两组均成功，候选释放使用中央相机即可。不是所有成功都依赖融合。
- 候选没有调用 inspect_support；stack/67 调用了两次 inspect_placement。不能把结果解释成“模型学会了选择主动取证技能”或“学会了点云融合算法”。融合属于受限 Runtime 观测能力，模型选择短程序并处理反馈。

原始 admission、模型请求、公开事件、独立评分均保留。详见 [independent-score.json](independent-score.json)，其中逐次保存释放检查的事件 ID 与证据引用。

## 结论与下一步

这些结果支持：在本轮限定方块仿真中，提供第二视角的系统可以自主走通更多闭环，并有实际释放保护使用融合证据的记录。两种子、每条件一次，模型输出也有随机性，不能宣称统计显著性、通用成功率或将全部差异归因于某个单独模块。候选仍保持显式开启，不自动替换默认策略。

本轮冻结代码不包含随后开发的独立持有监控。下一阶段分别检验：模型在独立监控中断后能否同场景恢复；多视角取证中停止、换目标和持续缺证据时的物理行为。碰撞检测、真机与跨硬件仍未验证，不以仿真完成代替。
