# 研究脚本与历史结果

这些目录保留项目的实验脚本、冻结清单、评分摘要及成功／失败报告。日期、种子、冻结版本分别记录；不同版本的结果不能直接合并成总体成功率。

本公开源码快照不包含机器专用的模型配置、访问令牌、加密用户配置、原始模型输入输出、完整执行状态、PNG／RGB-D、私有真值日志、压缩任务包，以及每轮重复的 source 冻结副本。原始资料仍保留在原工作区与服务器；部分历史文档链接指向这些未发布资料。

历史 prepare.py／Slurm／SSH 脚本包含当时机器的目录、端口及 GPU 配置，用于说明实验如何运行，不是通用部署命令。运行前需要在自己的环境配置路径、模型、服务和输出目录。冻结哈希描述当时源版本，不代表本公开仓库经过整理后的文件哈希。

可直接复用的当前产品实现位于 ../runtime、../frontend、../desktop、../cap-runtime；日常启动和测试按照根 README。研究用 SSH、模型配置读取辅助脚本不会进入桌面发行模块；发行清单由 runtime/scripts/stage-robot-runtime.mjs 检查。
