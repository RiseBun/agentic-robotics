# 主动补充观测：最小真实仿真实验

日期：2026-11-18。上一轮三面几何在接受子集上误差较小，但 39 个夹持帧中仅接受 16 个；关键失败放置帧仍不足三面。本轮检验改变观测条件能否补足信息，而非增加任务编排。

## 冻结的候选

使用固定短程序控制器，不调用模型；不是 LLM、通用机器人或真机成功率。所有动作通过受限 Runtime API，同任务只有一次环境初始化，保持默认 12 次控制器决策、40 次公开调用、1500 运动步、300 秒墙钟预算；被动几何计算和等待同样消耗墙钟。决策次数记录固定控制器的阶段选择，不能与实际模型推理成本等同。

- 两组共享初始抓取、抬起／持有检查、公开几何候选、公开尺寸参考、放置和释放代码。
- passive：不为感知新增动作，中心可估计时采用三面几何，否则沿用原可见包围盒中心。
- active：仅在已验证持有、中心仍 unknown 时，至多尝试两次转向；相对开始检查的 TCP 姿态绕基座 Z 轴 +25 度、-25 度，TCP 保持同一位置。每次重新完成公开 holding 检查，再刷新 RGB-D。估计可用即停止额外转向；仍不可估计则记录 unknown，并使用与 passive 相同的既有包围盒回退。回退不是精度保证。
- 最终放置保持当前姿态，不把检查前的偏移直接带到新姿态。无物体瞬移、不移动模拟相机、不读取物体真值选择动作。
- holding 检查失败或动作异常时停止本次试验并保留记录，不复位重做。先验证观察动作的可行性，本轮不同时研究抓取恢复。

每阶段等待 1.25 秒让公开窗口完成，仿真持续推进；这些等待计入墙钟。传感器读取采用该阶段最新公开状态引用的归档 NPZ，1 毫米量化值与上一轮候选一致。参考尺寸只能来自更早、开夹爪的公开完整观测。

## 实验次序和判据

开发检查：restack、seed=12、passive/active。新初态检查：stack/restack、seeds=21、22，每种两组；交替先后次序，所有配置、代码和阈值在执行前冻结。每组一次，帧和试验都不能当独立同分布大样本；不做显著性或总体成功率结论。首批可能因抓取或预算失败，必须保留在分母内。

分别报告：动作前后中心可估计性、实际新增转向、holding 丢失、公开完成声明、结束后私有任务结果、额外运动和墙钟。公开控制器不能接触 evaluation-private.jsonl；私有评分在运行结束后独立进行，并优先使用本轮记录的实际基座变换。

只有当主动观测确实改变下一次传感器证据且改善后续行为，才支持该机制；纯粹多看一次、几何覆盖率提高或某一条任务成功都不能独自证明完整系统更强。若新视角仍不足，就保留失败结果，进一步检查观测动作本身，不为通过而调宽判据。

这对应[综述中的部分可观测性约束](https://arxiv.org/html/2611.18359v1#S3.SS4)。[Closed-Loop Next-Best-View Planning for Target-Driven Grasping](https://jenjenchung.github.io/anthropomorphic/Papers/Breyer2022closed.pdf) 展示感知与动作连续更新的既有路线；[AURORA](https://aurorahand.github.io/) 用主动重定向补充固定相机观测。本轮仅验证普通夹爪的小幅检查动作，不复现这些论文的策略、硬件或性能。

## 已执行结果：本候选不晋升

10 次冻结试验全部执行并保存完整任务包。因指定 3090 节点排队，作业 20664 在分配资源之前取消（运行 0 秒），同一批源码和计划使用空闲 4090node1 的两张 RTX 4090，作业 20666 正常完成（5 分 55 秒）。没有把硬件切换后的耗时与此前 3090 实验直接比较。

- passive／active 各 5 次，私有结束窗口均为 3 次 verified、2 次 failed，均无误报完成、无 unknown。新初态子集 seeds=21、22 各 4 次，均 3 次完成；开发 seed=12 重堆叠两组均失败。
- active 实际增加 8 次转向，0 次把红方块中心从 unknown 变为 estimated；这只是中心可估计性计数，不是信息熵指标。seed=22 堆叠第二次转向后出现了三个面，但缺少此前公开尺寸参考，仍为 unknown。
- 新初态子集平均墙钟 passive 26.41 秒、active 34.29 秒，差 7.88 秒；每对仅一次，启动／缓存和调度成本未被充分消除。8 次转向合计增加 166 个运动步、16 次公开 API、8 次控制器阶段决策。
- 转向的实际 TCP 姿态确有变化，约 23.7～25 度；私有半秒采样未观测到转向期间双指接触丢失，不能由此保证没有瞬时滑移。

更关键的失败证据不是红方块是否能多看一面。开发 seed=12 两组的红方块中心已经可估计，离线水平误差约 1.35／1.38 毫米；绿色支撑物在抓持红方块后只剩约 61／62 个可见深度像素，包围盒中心偏差约 19.9 毫米，而此前释放绿色后的偏差约 3.1 毫米。新 seed=22 重堆叠中绿色支撑物不可见，两组均在放置前保留失败。已保存的 RGB 图像支持遮挡诊断，但这些数据还不能证明完整物理因果链。

因此不把固定转向脚本接入主模型或在线技能。下一候选应从“放置需要哪些当前事实”出发，分别检查持有、物体／TCP 偏移、支撑物位置及尺寸证据。支撑物不可见时，应验证让开视线是否能恢复支撑物观测；没有尺寸参考时，不应继续把同一种旋转当作解决办法。seeds=21、22 已完成分析，后续调参时应归入开发数据。

本轮新增实际基座变换记录已在 10 次真实 CaP 仿真中生成，独立评分使用这些实际变换；不再依赖旧批次的 XML 静态推导。所有 reset_count=1，未复位恢复。Python 完整 48 项测试通过；未改变生产动作策略、提示词或验证阈值，未重打包 EXE。完整证据位于毕业设计 `research/agentic_active_view_20261118/v1/`。

进一步检索的 [VA-TAMP](https://arxiv.org/html/2611.16213v1) 将计划所需的几何可见性作为执行前置条件，插入相应观察动作，并维护对象记忆。这提示下一步应围绕任务所需证据选择观察目标；其腕部相机、网格与 TAMP 求解器不是当前实验已具备的能力，也不需要整体移植才能验证这一原则。
