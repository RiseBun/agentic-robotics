# 公开几何估计：诊断协议

日期：2026-11-18。前一轮阶段证据候选版 5/6，旧版 6/6；本轮不能把框架可观测性当成抓放可靠性的替代品。

## 待检验的问题

夹持证据把可见点云包围盒中心相对 TCP 的偏移作为放置参考。夹爪遮挡会使可见中心偏离实体中心，稳定的偏移不代表准确的偏移。已有失败轨迹出现约 13 毫米的水平偏差，但尚未证明全部失败由它造成。

先在公开 RGB-D 上比较几何估计，不增加模型训练、长期记忆或硬件依赖。已有 seeds=11、12 均已看过，全部视为开发数据；以后使用的新种子才可作未见初态检查。

## 候选与拒绝条件（先记录，再测量）

旧估计为可见点云的逐轴 5%／95% 包围盒中心。诊断候选采用限定方块几何：从公开彩色点云拟合互相近似正交的平面，用公开早期完整观测估计边长，再推断中心。它不是通用物体姿态估计器。

- 颜色阈值、深度范围与最少 40 像素沿用现有感知。
- 归档深度量化为 1 毫米，因此平面内点阈值初始固定为 3 毫米；此值是开发假设，不是校准置信区间。
- 固定随机种子，限制点数、RANSAC 次数与平面数，记录运算耗时。
- 三个独立面不足、面不近似正交、可见跨度不足、无可用公开尺寸参考时返回 unknown，不凭偏差方向硬加修正量。
- 已有可见几何验证器的成功阈值和 holding 判断不随几何候选改变。
- 任何使用私有尺寸、物体姿态、接触、奖励或完成标记的候选不得进入运行接口。

比较覆盖率、中心误差、尾部误差、耗时与拒绝原因。必须同时报告拒绝的帧，不能只选估计成功的帧。私有真值只用于执行后的评分，不参与候选输入、尺寸参考选择或阈值修改。

## 数据与时钟

开发集来自上一轮冻结的完整任务包以及实际发给模型的观测引用。使用相同的归档 RGB-D 重放旧估计与候选，不把在线全精度结果和归档量化结果混合排名。记录量化误差限制。

公开几何与 FK 使用 CaP 基座坐标；私有物体位姿使用世界坐标。新记录应明确坐标系、单位、相机变换引用，并由独立评测器记录世界到基座的实际变换。旧记录只能使用源码 XML 的静态重建变换，必须保留这一限制。采样匹配使用 Runtime 时间，不假设工作台与服务器时钟同步。

## 为什么先不接重型姿态模型

[FoundationPose](https://github.com/NVlabs/FoundationPose) 支持 CAD 或 RGB-D 参考视图的姿态估计／跟踪；[BundleSDF](https://github.com/NVlabs/BundleSDF) 联合跟踪与重建未知刚体。它们说明多视图和形状建模是解决遮挡偏差的既有路线，但会引入额外参考数据、GPU 运行与延迟。本轮先验证当前限定方块是否可用公开几何解决，若观测不可辨识，再测多视图或现有跟踪器，而不是凭单帧中心输出虚假的精度。

这一顺序对应[综述 §3.4](https://arxiv.org/html/2611.18359v1#S3.SS4) 对新鲜观测、部分可观测性与部署成本的约束。即便离线中心误差降低，也必须另做同预算闭环实验，才能声称任务能力改善。

## 已执行的第一轮离线诊断

重放上一轮 12 个完整任务包中实际送给模型的 71 份观测，并为每份检查红／绿两种标签，共 142 个帧／标签组合。每个任务另取归档初始帧用于公开尺寸参考；候选不能使用本帧刚得到的尺寸进行本帧预测。尺寸只从先前开夹爪、三面近似正交且投影跨度一致的公开点云获得。没有调用模型、重置场景或执行机器人动作。

- 41/142 个组合可给出三面中心估计；72 个不足三面，20 个可见深度不足，9 个没有更早的公开尺寸参考。142 的分母包括抬起场景中并不存在的绿色物体标签，不能把它解释为目标物体可见率。
- 私有真值在预测文件冻结后才读取。16 个组合无对应私有物体，剩余 126 个满足当前稳定时间窗口；122 个可计算旧可见包围盒误差。
- 在共同接受的 41 个组合上，平均水平误差为旧估计 8.49 毫米、候选 1.29 毫米；候选最大 2.09 毫米。这只是接受子集上的离线开发结果，帧间相关，不能推断成功率或泛化收益。
- 私有双指接触为真的 39 个组合中，候选仅接受 16 个；其余 23 个不足三面。此前失败的重堆叠 seed=12 放置前红方块帧 `frame-001426.npz` 仍返回 unknown，候选不能直接解决这次失败。
- 本机每组合处理墙钟耗时中位数 9.72 毫秒、90 分位 12.50 毫秒，包含旧估计与候选；不是控制循环延迟或完整部署基准。

因此保留候选为离线实验，不替换在线夹持偏移。下一步需要验证主动改变观测条件或显式几何范围是否补足缺失信息；不要把“不足三面”放宽成未经验证的精确中心。

新增公开坐标系／单位元数据，并在私有评测器记录实际基座位姿，避免未来记录依赖 XML 静态推导。世界坐标变换只进私有评分记录，不进入模型观测。修改已通过坐标边界测试，尚未在新真实仿真任务中验证或更新发行 EXE。

复现入口：`cap-runtime/experiments/replay_public_geometry.py` 只读公开传感器；`score_public_geometry.py` 在预测冻结后独立评分。首次 v1 源码与原始预测、私有评分、源文件检查保存在毕业设计目录 `research/agentic_geometry_20261118/probe-v1/`。旧档案的坐标变换仍是源码推导，不可声称完成真机标定。

新增检索中，[AURORA 官方项目](https://aurorahand.github.io/) 展示了固定相机下通过不确定性驱动的物体重定向补充观测，但其 Leap Hand 与 BundleTrack 管线不同于当前普通夹爪，代码链接仍标为 Coming soon。[TiPToP 实现说明](https://tiptop-robot.github.io/implementation) 明确单视角与开环执行限制，并把手内位姿／滑落检测列为扩展方向。这些是方法取舍的参照，不是本系统已获得的能力，也不能直接比较性能。
