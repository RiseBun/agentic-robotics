## 当前边界

## 第一项主动取证的验收门

1. 单元边界：只有新鲜、有限位置与充分尺寸证据才 available；最多两个有限侧向目标；持有失败停止；取消和预算不被绕过。
2. Episode 集成：unknown→available、unknown→unknown、取证中停止／换目标、重复请求、遮挡下禁止完成声明、导出事件可关联。新增独立 fixture 测试使用真实 Episode／解释器／事件路径；它们不证明物理能力。
3. 固定程序：冻结 Runtime，`cube_stack`／`cube_restack`，61／62，passive 与 support_active 各一次。开发／历史结果单列；独立评分在所有 episode 关闭后进行。
4. 模型对照：固定模型和预算，保持共同的证据规则和 Runtime 保护，仅改变 `inspect_support` 的可用性；每对交替顺序。单独报告自主调用、真实物理结果、当时公开确认、错误完成、unknown 恢复率与成本。
